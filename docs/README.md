# 지투라이브 문서 안내

GitHub에서 프로젝트를 처음 보거나 과거 의사결정을 다시 확인할 때 이 문서부터 읽는다.

## 먼저 읽을 문서

1. [프로젝트 소개](./product/프로젝트_소개.md)

   프로젝트 목적, 대상 사용자, 핵심 원칙과 현재 공개 범위를 설명한다.

2. [프로젝트 개발 히스토리](./product/프로젝트_개발_히스토리.md)

   기획 변화, 장애 해결, 데이터 알고리즘, 기술적 의사결정과 예상 질문을 기록한다.

3. [현재 개편 설계: KRX·NXT 세션별 추정가](./superpowers/specs/2026-09-02_KRX_NXT_세션별_추정가_개편_설계.md)

   현재 진행 중인 한국 주식 추정가·차트·오차 측정 개편의 기준이다.

4. [참고자료와 선정 이유](./reference/참고자료와_선정이유.md)

   기능과 데이터 정책을 결정할 때 확인한 공식 문서, 실제 적용 범위, 선택 이유와 한계를 기록한다.

5. [차트 선행 데이터·그리기 도구 설계](./superpowers/specs/2026-09-02_차트_선행데이터와_그리기_도구_설계.md)

   MA 120·180과 선 그리기를 검토한 과정, 2017년 장기 이력의 공급자 한계와 0.4.0 보류 결정을 기록한다.

## 기록 원칙

- `README.md`: 현재 동작, 실행 방법과 기술 스택
- `CHANGELOG.md`: 버전별 사용자 영향 변경
- `product/프로젝트_개발_히스토리.md`: 문제, 대안, 선택 이유, 구현 원리, 결과와 한계
- `superpowers/specs/`: 승인된 제품·아키텍처 설계
- `superpowers/plans/`: 설계를 구현하기 위한 작업 순서와 검증 절차
- `reference/참고자료와_선정이유.md`: 외부 공식 문서, 확인일, 적용 범위, 선정 이유와 재검토 조건

기능 기획, 공급자, 알고리즘 또는 UI 정책이 바뀌면 코드와 함께 해당 문서를 같은 작업에서 갱신한다. 확인하지 않은 예정 사항은 완료된 기능으로 기록하지 않는다.
