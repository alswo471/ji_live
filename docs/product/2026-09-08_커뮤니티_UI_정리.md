# 커뮤니티 UI 정리

## 배경과 승인 범위

공식 일별 데이터 연동을 feature push한 후 `6d99347`로 develop에 병합·push했다. 양쪽에서 테스트 539개 통과·6개 skip을 확인했다. 이어 사용자가 승인한 목록 밀도 개선, 버튼으로 여는 글쓰기, 본문→댓글→작성 순서, 관리자 디자인 통일을 `feature/community-ui-polish`에서 진행했다. 기존 미리보기 worktree와 개인 설정을 보존했다.

## 변경 내용과 이유

- 목록: 행 간격을 줄이고 댓글 수를 제목 바로 옆에 배치했다. 제목·요약·작성자·시각·참고 도메인은 유지한다. 실제 없는 인기 점수나 순위를 만들지 않는다.
- 글쓰기: 초기에는 닫혀 있으며 버튼의 expanded 상태로 열림 여부를 전달한다. 열면 제목에 초점이 이동한다. 폼은 접어도 유지되어 작성 중 입력이 사라지지 않는다. 페이지 이동·새로고침까지 보존하는 기능은 아니다.
- 상세: 제목과 작성자·작성시각, 본문, 댓글 목록·더 보기, 댓글 작성 순서로 배치했다. 긴 문자열이 화면을 밀어내지 않도록 줄바꿈을 추가했다.
- 관리자: 큰 홍보형 제목·배경 장식을 줄이고 일반 커뮤니티와 동일한 배경·폭·간격을 적용했다. 공통 footer를 추가했다. 기존 신고·숨김·삭제 대기·제재·운영 로그 탭과 권한은 유지한다.

## 유지한 경계

인증, Turnstile 검증, API, DB, 신고 기준, 관리자 권한, 1년 보관·파기 정책은 변경하지 않았다. 검색·정렬 확장, 게시글 수정 기능, 공개 전환, 실제 Supabase 쓰기·관리 조치는 이번 범위가 아니다.

현재 미리보기 환경의 커뮤니티 공개 flag는 비활성 상태를 유지한다. 해당 환경에서는 준비 화면이 나오는 것이 정상이며, 이 변경만으로 공개 준비가 완료된 것은 아니다. 실제 인증을 포함한 E2E와 모바일·라이트/다크 육안 검증은 별도 개발 설정에서 진행해야 한다.

## 참고와 검증

- 기존 `docs/superpowers/specs/2026-09-03-익명-커뮤니티-설계.md` 및 기존 페이지·폼·관리 구성의 인터페이스를 유지했다.
- UI/UX skill 검색: `progressive disclosure forms`는 직접 관련성이 낮아 채택하지 않았다. `keyboard focus disclosure`의 Focus States·Focus Not Obscured 지침을 참고해 버튼 초점 표시와 제목 초점 이동을 적용했다. 새로운 외부 디자인·이미지·라이브러리는 사용하지 않았다.
- TDD: 최초 글쓰기 노출과 댓글 작성 폼이 댓글보다 앞선 순서를 테스트로 확인해 2개 실패를 재현했다. 구현 후 관련 16개 테스트가 통과했다. 접기·재열기 시 초안 보존과 공개 flag 비활성 상태도 확인했다.

- 최종 전체 검증: 79개 파일, 541개 테스트 통과·6개 skip. TypeScript·lint·production build 모두 통과했다. 기존 Vinext 정적 route 분류 안내는 유지된다.
- Read-only 코드 리뷰에서 확인된 회귀·접근성 결함은 없었다. 단, 테스트에서는 외부 Turnstile을 대체하므로 숨겨진 작성 영역에서 실제 위젯 초기화·펼침 후 검증 동작은 E2E 확인이 남아 있다. 성공한 것으로 간주하지 않는다.
