# OO라이브 프로젝트 기획 요약

## 프로젝트 정의

OO라이브는 한국·미국 주식, 암호화폐와 핵심 시장 지표를 한 화면에서 확인하는 공개용 실시간 시장 대시보드다. 지민재가 기획, UI/UX, 시세 API, 테스트, GitFlow, CI/CD와 배포를 학습하며 제품 개발의 전 과정을 기록하는 개인 공부 프로젝트이다.

## 해결하려는 문제

국내 주식은 정규장이 끝나면 사용자가 관심 종목에 영향을 주는 해외 시장의 변화를 여러 서비스에서 각각 찾아야 한다. OO라이브는 장중에는 실제 시세를 보여주고, 시세가 제공되지 않는 시간에는 해외 연관 지표로 계산한 참고 추정가를 분명히 구분해 제공하는 것을 목표로 한다.

## 대상 사용자

- 국내·해외 주식과 코인의 흐름을 한번에 보고 싶은 개인 사용자
- 정규장 이후에도 국내 주식에 영향을 줄 수 있는 해외 지표를 보고 싶은 사용자
- 복잡한 전문가용 터미널보다 읽기 쉬운 시장 요약을 원하는 사용자

## 핵심 제품 원칙

1. 실제 시세가 있을 때는 항상 추정가보다 우선한다.
2. 실시간, 지연, 장 마감과 참고 추정 상태를 사용자가 오인하지 않게 표시한다.
3. 추정가에는 기준 시각, 연관 지표와 신뢰도를 함께 표시한다.
4. 공급자 오류 시 임의의 고정 가격을 실제 시세처럼 노출하지 않는다.
5. 색만으로 상승·하락을 구분하지 않고 부호와 텍스트를 함께 제공한다.
6. 공개 배포판에는 개인 계좌, 보유종목, 평단가와 수익률을 포함하지 않는다.
7. 투자 권유가 아닌 학습·정보 확인용 서비스로 제공한다.

## 1차 개편 범위

- 한국 주식 대표 10종목
- 미국 주식 대표 10종목
- 암호화폐 5종목
- KOSPI, USD/KRW, NASDAQ 100 연동(QQQ), 금 연동(PAXG) 지표
- 프리장·정규장·애프터장·장 마감·참고 추정 상태
- 종목 상세 가격·거래량 차트
- 공급자, 기준 시각, 추정 근거와 신뢰도 표시

## 1차 제외 범위

- 로그인과 회원별 설정
- 개인 토스증권 보유자산
- 관심종목 저장
- 매매, 알림과 포트폴리오 분석
- 복잡한 AI 학습 모델

QQQ와 PAXG는 각각의 실제 거래 시세를 표시하되 NASDAQ 지수나 금 현물로 표현하지 않는다. 장이 닫힌 한국 주식의 참고 추정가를 계산할 때는 이 프록시 상품의 실제 변동률을 입력값으로 사용할 수 있다.

## 성공 기준

- 시장 세션에 맞는 실제 현재가가 추정가보다 우선 표시된다.
- 시세 미제공 시간에는 설명 가능한 참고 추정가와 신뢰도가 표시된다.
- 공급자 하나가 장애를 일으켜도 다른 자산군 화면은 계속 사용할 수 있다.
- 375px 모바일부터 1440px 데스크톱까지 핵심 정보를 읽고 조작할 수 있다.
- 상승·하락 상태를 색, 부호와 텍스트로 함께 식별할 수 있다.

## 발전 방향

1차에서는 연관 상품, 업종 지표와 환율의 가중평균을 사용해 설명 가능한 추정가를 만든다. 이후 추정가와 다음 실제 시세의 오차를 누적해 종목별 민감도와 가중치를 보정한다. 정확도가 검증되기 전까지 추정가는 투자 판단용 실시간 시세가 아닌 참고 정보로만 취급한다.
