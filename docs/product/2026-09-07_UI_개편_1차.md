# UI 개편 1차: 시장 탐색

> 아래 본문은 1차 시점의 기록이다. B2·문의·심리지수의 후속 적용과 남은 요구사항은 [UI 후속 개편 기록](./2026-09-07_UI_후속개편.md)을 참고한다.

## 배경과 범위

2026-09-07, 커뮤니티 운영화면을 develop에 병합한 뒤 사용자가 다음 UI 개편 진행을 승인했다. 최신 develop에서 `feature/ui-refresh` worktree를 만들었다. 과거 디자인 브랜치로 돌아가 커뮤니티 작업을 누락하지 않는다.

사용자는 큰 홍보 문구와 기존 로고를 개선하고, 한국·미국 주식·ETF·뉴스·커뮤니티로 탐색할 수 있는 구성을 요청했다. 이번 차수는 공통 메뉴와 마켓 화면 구조에 집중한다. 시세 공급자, 커뮤니티 권한, 개인정보 보존 정책은 변경하지 않는다.

## 적용 내용과 이유

- 기존 큰 hero를 제거하고 시장 요약 → 종목 목록 → 데이터 안내 순으로 배치한다. 첫 화면에서 가격을 찾기 쉽게 한다.
- 한국 주식·미국 주식·암호화폐·ETF·뉴스 메뉴를 작은 화면에서도 사용할 수 있게 한다. 커뮤니티는 기존 공개 feature flag를 유지한다. 관리자 메뉴는 공개 navigation에 추가하지 않는다.
- `/?market=us-stock`처럼 시장을 URL에 보존한다. 유효하지 않은 값은 한국 주식으로 처리한다.
- 종목 검색은 현재 시장의 한글명·영문명·심볼에 한정한다. 빈 결과에서는 검색 초기화를 제공한다.
- 파생 추정가와 거래상품 가격의 차이는 오른쪽 안내와 기존 개별 quote badge로 설명한다. 가짜 가격이나 공포·탐욕 수치를 생성하지 않는다.
- 공통 header 높이가 증가하여 커뮤니티 작성 영역의 sticky 간격을 조정한다.

## 이번 차수에 완료하지 않는 항목

- B2 캐릭터: 현재 checkout에서 승인 원본을 찾지 못했다. 임의로 다른 캐릭터를 만들지 않고 기존 로고를 유지한다. 원본 확보 후 적용한다.
- ETF·뉴스: 메뉴와 준비 화면만 제공한다. 데이터 공급·이용 조건 검토와 실제 연동은 별도 작업이다.
- 인기 한국/미국 각 20종목, 거래량 상위 ETF 10종목, 추가 환율 및 시장별 공포·탐욕 지수: 기존 공급 범위를 그대로 유지하며 후속으로 진행한다.
- Oracle 배포 URL, 문의 링크는 임의로 채우지 않는다.

## 참고와 검증

기존 `SiteHeader`, `QuoteTable`, `IndicatorGrid`, `useMarketDashboard`, 공통 footer 및 커뮤니티 feature flag 구조를 기준으로 구현했다. `ui-ux-pro-max`의 금융 dashboard navigation UX 검색 결과 중 키보드 접근, 고정 메뉴의 콘텐츠 가림 방지 기준을 적용했다. 외부 사이트 이미지·기사·브랜드 자산은 새로 복제하지 않았다. 본 기록은 법률 적합성이나 데이터 재배포 권리 확인을 대신하지 않는다.

검색, 잘못된 시장 fallback, URL 시장 선택, ETF·뉴스의 종목 혼합 방지를 component test로 검증했다. 전체 테스트 491개 통과·6개 skip. lint의 상태 안내 태그·내부 링크 지적을 수정한 뒤 lint, TypeScript, 관련 component test 4개를 다시 통과했다. 브라우저에서 라이트·다크 메인 화면, 미국 주식 메뉴 이동과 기존 공급자 데이터 표시를 확인했다. 모바일 실기기 검증은 아직 수행하지 않았다.

미리보기는 `http://127.0.0.1:3002/`이며 공개 배포 주소가 아니다. 새 worktree에 개인 환경변수를 복제하지 않아 커뮤니티 메뉴는 기존 feature flag 기본값에 따라 숨겨진다. 이는 커뮤니티 기능 삭제가 아니다.
