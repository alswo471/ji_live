# UI 후속 개편과 남은 요구사항

## 작업 순서

사용자의 요청에 따라 UI 1차를 `71e293a`로 commit·feature push하고, `a714241`로 develop에 merge·push했다. 두 tree에서 테스트 491개 통과·6개 skip을 확인했다. 후속 작업은 같은 worktree를 보존한 채 최신 develop에서 `feature/ui-completion`으로 분리했다. 기존 미리보기와 개인 설정을 지우지 않는다. main·release는 변경하지 않았다.

## 이번 적용

- B2 원본: 사용자가 다시 첨부한 오트밀색 쫑긋귀 캐릭터를 `public/brand/g2-b2.png`에 원본 그대로 보관하고 공통 header에 하나만 표시한다. 캐릭터를 재생성하거나 여러 버전으로 복제하지 않는다.
- 문의: 사용자가 제공한 `https://open.kakao.com/o/svBZhtMi`를 피드백·광고 문의에 연결한다. 개인정보·권리침해 문의 release gate 설정과 분리한다.
- 커뮤니티: 큰 홍보 heading과 개별 대형 카드를 줄이고 제목·요약·작성자·시각·댓글 수 중심 게시판형 목록으로 정리한다. 좁은 화면에서 글쓰기 영역으로 이동하는 anchor와 운영정책 링크를 제공한다. 세션·CAPTCHA·write·신고·관리 권한은 그대로 유지한다.
- 심리지수: Alternative.me의 실제 비트코인 공포·탐욕 값을 별도 API에서 읽어 게이지에 표시한다. 한국·미국 주식 지수로 부르지 않는다. 출처를 값 바로 옆에 링크하고 원본 UTC 기준일과 갱신 지연 상태를 표시한다.

## 심리지수 데이터 흐름과 안전장치

브라우저 → `/api/market/sentiment` → 기존 `createCachedProvider` → Alternative.me `/fng/?limit=1` 순서다. 기존 5초 시세 수집과 분리하므로 심리지수 장애가 주식 목록을 막지 않는다.

서버 캐시는 1시간, 동시 요청은 하나로 병합, 공급자 timeout은 5초다. 실패 시 회로 cooldown을 적용하고, 마지막 정상값이 있다면 stale 표시로 제공하되 원본 기준일이 72시간을 넘으면 숫자를 반환하지 않는다. 미래 기준시각, 0–100 범위 밖, 정수가 아닌 값, 미지원 분류, 공급자 error를 거부한다. 브라우저는 5분마다 보이는 탭에서만 다시 요청하며 실패 시 가짜 게이지를 표시하지 않는다. 캐시는 프로세스 단위로, 여러 서버 간 공유 cache는 아니다.

## 참고자료와 선정 이유 — 2026-09-07 확인

- [Alternative.me 공식 지수/API](https://alternative.me/crypto/fear-and-greed-index/): 출처를 표시값 옆에 명시하는 조건으로 상업적 이용을 허용한다. 비트코인 대상 일별 지수임을 명확히 안내한다. 사이트 사칭이나 동일 서비스 오인 금지 조건도 유지한다. 독자적인 종합시장 지수로 재포장하지 않는다.
- [Frankfurter 공식 문서](https://frankfurter.dev/): USD·JPY·THB 등 추가 환율 후보로 조사했다. 일별 기준환율이며 실시간 거래용이 아니다. API 상업 이용과 별개로 기초 데이터 공급자 약관 확인이 필요하므로 아직 연결하지 않았다.
- `ui-ux-pro-max`: 최초 design-system 검색의 Enterprise Gateway·영업용 hero 제안은 금융 게시판과 맞지 않아 채택하지 않았다. 좁은 화면에서 표가 넘치지 않도록 하는 Table Handling 지침과 기존 theme token을 적용했다.
- 로고는 사용자가 제공한 생성 이미지 원본이다. 경쟁 서비스의 로고를 다운로드하지 않았다. 본 기록은 상표·저작권 무침해를 보증하는 법률 검토서는 아니다.

## 검증 결과

- 전체 테스트 501개 통과·6개 skip, TypeScript·lint·production build 통과.
- 심리지수 숫자·기준시각 검증 8개와 게이지 성공·실패 표시 2개 추가. 기존 Home fetch fixture는 새 요청과 응답 body를 공유하지 않도록 URL별 응답으로 수정.
- next/image 도입에 맞춰 Vitest도 실제 Vinext image shim을 해석하도록 별칭 추가. 이미지 자체는 원본 PNG를 사용하며 용량 최적화는 미적용.
- 실제 로컬 `/api/market/sentiment` 정상 응답과 브라우저의 B2 로고·71점 게이지·UTC 기준일·출처·카카오 문의 목적지를 확인. 값은 검증 시점의 값이며 이후 변한다.
- 이 worktree에는 개인 환경변수를 복사하지 않았으므로 커뮤니티 공개 flag는 기본값 false다. 게시판·작성 기능은 component test로 확인했으며 이번 차수에는 실제 Supabase write나 관리자 조치를 재실행하지 않았다. 모바일 실기기 확인은 남아 있다.
