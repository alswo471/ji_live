# 지투라이브 프로젝트 기획 요약

## 프로젝트 정의

지투라이브는 한국·미국 주식의 해외 파생상품 기반 추정가, 암호화폐와 핵심 시장 지표를 한 화면에서 확인하는 공개용 24시간 시장 참고 대시보드다. 지민재가 기획, UI/UX, 공개 시장 데이터 API, 테스트, GitFlow, CI/CD와 배포를 학습하며 제품 개발의 전 과정을 기록하는 개인 공부 프로젝트이다.

## 해결하려는 문제

국내·미국 주식의 정규장이 끝난 뒤에도 해외 파생시장은 움직이지만, 그 가격은 기초 주식의 실제 체결가와 성격이 다르다. 지투라이브는 검증된 해외 파생상품 가격을 24시간 참고 추정가로 제공하되, 실제값과 추정가를 혼동하지 않도록 가격 성격, 비교 기준, 공급자와 기준 시각을 함께 표시한다.

## 대상 사용자

- 국내·해외 주식과 코인의 흐름을 한 번에 보고 싶은 개인 사용자
- 정규장 이후에도 주식 연동 해외 파생상품의 변화를 참고하고 싶은 사용자
- 복잡한 전문가용 터미널보다 읽기 쉬운 시장 요약을 원하는 사용자

## 핵심 제품 원칙

1. 주식 파생 가격은 시장 세션과 관계없이 항상 `24시간 추정가`로 표시한다.
2. 실제 거래상품, 파생 추정가와 데이터 미제공 상태를 사용자가 오인하지 않게 구분한다.
3. 추정가에는 공급자, 기준 시각, 비교 기준과 환산 근거를 함께 표시한다.
4. 검증되지 않은 종목·가격·등락률을 만들지 않는다.
5. 공급자 오류 시 임의의 고정 가격을 실제값처럼 노출하지 않는다.
6. 상승·하락은 색뿐 아니라 부호와 텍스트로도 구분한다.
7. 투자 권유가 아닌 학습·정보 확인용 서비스로 제공한다.

## 0.4.0 공개 범위

- 한국 주식 7종목의 Hyperliquid·Binance 파생상품 기반 원화 환산 추정가
- 미국 주식 4종목의 Binance 무기한선물 기반 USDT 추정가
- Bithumb 원화 암호화폐 5종목과 Binance PAXG 실제 거래상품 가격
- Bithumb `KRW-USDT` 기반 합성환율과 환산 근거
- 24시간 추정가, 실제 거래상품, 데이터 미제공 및 갱신 지연 상태
- 공급자, 기준 시각과 `24시간 전 대비` 표시
- 제공 가능한 종목의 1분·15분·1시간·4시간·일봉·주봉·월봉 상세 차트
- 한글명·영문명과 라이트·다크 표시 전환

## 0.4.0 제외 범위

- KRX·미국 거래소 실제 체결가 제공
- 한국 주식 원화 환산 상세 차트
- 검증되지 않은 주식 파생상품 mapping
- 로그인과 회원별 설정
- 매매, 알림과 포트폴리오 분석
- 자동매매 신호와 가격 정확도 보장

## 데이터와 차트 원칙

- Hyperliquid는 검증된 한국 주식 연동 파생상품 가격을 제공한다.
- Binance는 검증된 한국·미국 주식 연동 USDT 무기한선물과 PAXG/USDT 현물 가격을 제공한다.
- Bithumb는 원화 암호화폐와 원화 환산용 `KRW-USDT` 합성환율을 제공한다.
- 주식 등락률은 임의 전일 종가를 섞지 않고 공급자의 `24시간 전 대비`를 사용한다.
- 한국 주식 추정가는 파생상품 가격에 합성환율을 적용하며, 은행 고시환율 또는 실제 KRX 가격으로 표현하지 않는다.
- 목록 현재가는 5초, 1분·15분·1시간봉은 60초, 4시간봉은 30분, 일봉·주봉·월봉은 6시간 cache를 사용한다.
- 한국 주식은 과거 시점별 원화 환산 근거가 없어 `0.4.0`에서 상세 차트를 제공하지 않는다.
- 종목 상세는 공유 가능한 고유 URL을 사용하고 OHLC·거래량과 데이터 미제공 상태를 함께 보여준다.

## 성공 기준

- 모든 한국·미국 주식 가격이 실제 체결가가 아닌 24시간 파생 추정가로 명확히 표시된다.
- 공급자, 기준 시각, `24시간 전 대비`와 원화 환산 근거를 확인할 수 있다.
- 공급자 하나가 장애를 일으켜도 다른 자산군 화면은 계속 사용할 수 있다.
- 데이터가 없거나 오래되면 임의 숫자 대신 미제공 또는 갱신 지연 상태를 표시한다.
- 375px 모바일부터 1440px 데스크톱까지 핵심 정보를 읽고 조작할 수 있다.
- 상승·하락 상태를 색, 부호와 텍스트로 함께 식별할 수 있다.

## 발전 방향

정식 시장 데이터 계약이 마련되면 실제 주식 가격을 별도 계층으로 추가하고, 파생 추정가와 조용히 섞지 않는다. 파생 추정가와 다음 정규장 실제 시가의 오차를 기록해 참고 정확도를 평가하고, 공식 공개 API에서 계약과 가격 범위를 검증한 종목만 단계적으로 확대한다.
