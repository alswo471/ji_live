# 지표 상단 배치와 출처 팝업

## 최신 추가 피드백 — 전광판 버튼·스크롤바 제거

사용자 요청으로 전광판 옆 정지·재생 버튼과 클릭/초점 시 나타나던 가로 스크롤바를 제거했다. 원인은 focus-within 및 reduced-motion에서 적용되던 overflow-x:auto였다. 해당 전환을 제거하고 overflow-hidden을 유지한다. hover·키보드 초점 정지와 reduced-motion은 유지하며 잘린 전체 항목은 전광판의 시장 지표 상세 링크에서 확인할 수 있다. 아래 버튼·수평 탐색 관련 내용은 이전 구현 이력이다.

## 요청과 결정

사용자는 환율·금·공포지수가 화면 곳곳에 흩어진 점과 지표 아래 긴 출처 설명으로 정보가 복잡해진 점을 지적했다. 홈 최상단의 메뉴 아래에 요약을 모으고, 시장 지표 전용 페이지와 하단 출처 팝업으로 상세 설명을 분리했다. 기존 테마·브랜딩은 유지했다.

- 홈: 금(PAXG), USD 1·JPY 100·THB 1의 일별 기준환율, 비트코인 공포·탐욕을 상단에 배치. 긴 우측 안내를 없애 종목 목록을 넓게 사용한다.
- 시장 지표 `/indicators`: 환율 상세, 금 연동 상품, 시장별 심리 구역 제공.
- 한국·미국 주식 심리와 코스피·나스닥은 아직 데이터 미연동. 점수·지수값을 만들거나 비트코인 지수로 대체하지 않는다. 이 요구사항은 데이터 연동 완료가 아니다.
- USDT/KRW 카드는 제거하되 서버의 원화 추정가·차트 환산 데이터는 유지한다. ECB 일별 환율로 계산 원리를 바꾼 것이 아니다.
- 공통 footer의 `데이터 출처·산정 기준` 버튼에서 제공처, 계산식, 주기, 유의사항을 확인한다. 기존 Base UI Dialog를 사용해 초점 관리와 닫기를 제공한다. 개인정보처리방침 등 기존 법적 문서의 페이지와 내용은 변경하지 않았다.
- 일별 기준·발표일·갱신 지연 등 가격 해석에 필요한 표시는 남긴다. Alternative.me의 값 인접 출처 표기는 작은 링크로 유지한다.

## 참고와 이유

- [Alternative.me](https://alternative.me/crypto/fear-and-greed-index/): 기존 연동 검토에서 확인한 값 옆 출처 조건을 유지. 출처 팝업만으로 대체하지 않았다.
- [ECB](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html), [이용 조건](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html): ECB 출처와 교차계산 사실은 팝업에서 확인 가능. 데이터 계산 자체는 [기존 환율 기록](./2026-09-07_ECB_기준환율_연동.md)과 동일하다.
- [Frankfurter](https://frankfurter.dev/): 기존 ECB 단일 공급자 fallback 경로를 팝업에 기록. 공급자나 이용 범위를 새로 확대한 작업이 아니다.
- UI/UX Pro Max: design-system 검색의 Enterprise Gateway 권고는 기존 금융 화면과 맞지 않아 미채택. `keyboard focus modal` 검색의 가시적 초점과 초점 가림 방지 지침을 적용했고 기존 theme token을 유지했다.

## 검증과 범위

아래는 첫 카드형 반영 시점의 기록이며, 이후 같은 날 추가 피드백으로 전광판 형태로 변경했다.

- 새 메뉴 및 하단 팝업 테스트가 변경 전 실패하는 것을 확인한 뒤 구현했다.
- 전체 테스트 515개 통과·6개 skip, TypeScript·lint·production build 통과. 기존 Vinext의 일부 route 정적 분류 안내는 남아 있다.
- 로컬 브라우저에서 실제 금·환율·비트코인 값과 상단 배치를 확인했다. API 수집·개인 인증·커뮤니티 DB는 변경하지 않았다.
- 모바일 실기기 확인은 미실시. 데이터 미연동 항목은 미완료로 유지한다.
- 이번 기록은 로컬 feature/ui-completion 작업 기준이다. 공개 배포 및 develop 병합을 의미하지 않는다.

## 추가 피드백 — 얇은 전광판 및 비트코인 그래프 위치

사용자는 큰 상단 카드가 아닌 화면 맨 위의 얇은 이동 전광판을 원했다. 승인 후 로고 위 44px 높이 한 줄로 금·달러·100엔·바트를 배치했다. 공포·탐욕은 전광판에서 빼고 BTC 상세와 시장 지표 페이지 두 곳에 둔다. 다른 코인 상세에는 비트코인 심리를 추가하지 않는다.

- 오른쪽에서 왼쪽으로 45초 주기의 일정한 속도로 이동한다. 반복용 복제 구역은 보조기기에 중복 낭독되지 않도록 숨긴다.
- 일시정지·재생 버튼, 마우스 hover 정지, 키보드 초점 시 정적 표시를 제공한다. OS의 reduced-motion 설정에서는 이동을 제거하고 수평 탐색을 허용한다.
- 전광판을 누르면 시장 지표 상세로 이동한다. 일별 날짜·통화 단위·변동률·지연 상태를 유지하고 새로운 시세 공급자를 추가하지 않았다.
- 전광판과 기존 환율 상세가 같은 검증·갱신 로직을 쓰도록 useReferenceFx로 분리했다. 반복 표시는 동일 응답을 재사용하므로 전광판 안에서 API를 두 번 호출하지 않는다.
- UI/UX Pro Max의 최초 pause 검색은 관련성이 낮아 미채택. 재검색한 Reduced Motion 지침을 적용했다. 기존 CSS animation과 Lucide 아이콘만 사용하고 새 라이브러리는 추가하지 않았다.
- 상단에서 심리지수 제외·정지/재생 상태 전환·BTC/ETH별 게이지 노출 테스트를 확인했다. 전체 517개 통과·6개 skip, 타입·lint·build 통과. 데스크톱 브라우저에서 전광판 배치를 확인했다. 모바일 실기기와 OS reduced-motion의 수동 검증은 미실시다.
