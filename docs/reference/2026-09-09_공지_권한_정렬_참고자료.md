# 공지·필독 권한과 정렬 참고자료

확인일: 2026-09-09. 관리자만 게시글 종류를 선택하고, 목록에서 필독·공지·일반을 구분하려는 요구사항을 위한 자료다.

## 참고 문서와 적용 이유

| 문서 | 확인한 내용 | 프로젝트에서 참고하는 이유 |
| --- | --- | --- |
| [PostgreSQL — Sorting Rows](https://www.postgresql.org/docs/current/queries-order.html) | 결과 순서는 명시적인 정렬로 보장하며, 여러 정렬 기준은 앞 기준이 같을 때 다음 기준을 적용한다. | 첫 화면만 재정렬하지 않고 DB 조회와 다음 페이지 커서에 같은 종류·작성일·ID 순서를 적용한다. |
| [Supabase — Row Level Security](https://supabase.com/docs/guides/database/postgres/row-level-security) | 권한 부여와 행 정책은 별개이며, service_role은 RLS를 우회하므로 서버에서만 사용해야 한다. | 관리자 버튼 노출 여부만 믿지 않고 서버 인증, 관리자 등록 확인, DB 쓰기 권한을 함께 검증한다. |

## UI 참고 범위

- 사용자가 제공한 네이버 카페 게시판 캡처의 `필독`·`공지` 배지, 강조색, 날짜 표기를 배치 참고로 사용한다.
- 캡처의 게시글 문구, 카페 이름, 이미지 자산은 서비스 콘텐츠로 복사하지 않는다.
- 관리자 표시와 게시글 종류는 서로 다른 개념이다. 이번 선택지는 `일반 / 공지 / 필독`이다.

## 기록 범위와 주의사항

- 이 문서는 설계 근거이며 적용·테스트 완료 증거를 대신하지 않는다. 실제 구현 결과는 해당 구현 이력에서 별도로 기록한다.
- 문서를 참고했다고 저작권·이용조건 검토가 모두 완료되거나 적법성이 보장되는 것은 아니다. 외부 코드·이미지·데이터를 도입할 때는 해당 조건을 별도로 확인한다.
- 원격 DB 반영 여부는 로컬 구현 완료 여부와 구분해 기록한다.
