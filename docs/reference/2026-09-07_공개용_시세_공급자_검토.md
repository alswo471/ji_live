- [Massive 개인 가격표](https://massive.com/pricing?product=stocks): Starter 15분 지연 월 29달러지만 개인용이다. 저렴하다는 이유로 공개 사이트에 채택하지 않는다.

- [Twelve Data Business 가격표](https://twelvedata.com/pricing-business): Venture 월납 499달러 표기. [미국 주식 안내](https://support.twelvedata.com/en/articles/9935903-us-equities-market-data)는 외부 배포를 위한 add-on과 별도 권한 절차를 설명한다. Basic/free 또는 저가 개인용이 모든 미국 시세 공개권을 준다고 가정하지 않는다.
- Twelve Data의 이전 지원 문서에는 149달러부터라는 문구가 있으나 현재 가격표와 불일치한다. 이 검토는 현재 가격표를 우선하며 최종 계약 가격은 견적 확인 대상이다.

위 두 업체 검토만으로 시장에 예산 내 대안이 전혀 없다고 단정하지 않는다. 미국 실제 체결가·ETF·나스닥 지수의 저비용 공개 공급자는 아직 확정하지 않았다.

- CNN의 비공식 endpoint나 제3자의 미러가 존재하는 사실만으로 미국 주식 심리지수 재배포 권한을 인정하지 않는다. 이번에는 공식 허용 API를 확정하지 못했다.
- 한국 자체 심리지수는 원천 데이터 권한, 산식, 검증 기간을 먼저 정해야 한다. 임의 점수를 공인 공포·탐욕지수로 표시하지 않는다.
- Bithumb·Binance·Hyperliquid는 이번 조사로 상업 재배포가 새로 승인된 것이 아니다. 현재 개발 연동 유지와 공개 출시 승인은 구분하며, 원천 데이터 및 파생값 표시 권리를 공개 gate에서 별도 재검토한다.

## 추천하는 다음 구현 범위 — 사용자 확인 전 미구현

1. 현재 파생 추정가와 별도 영역으로 국내 공식 일별 종가·코스피·ETF를 추가한다.
2. 최신 기준일이 실제 확보된 날짜임을 표시한다. 다음 영업일 제공 지연 때문에 주말에 금요일 값이 아직 없을 수도 있다. 데이터가 없는 날짜를 가짜 보간으로 채우지 않는다.
3. ETF 상위 10개와 주식 종목 확대는 같은 기준일의 전체 페이지 수집이 끝난 뒤 선정한다. 일별 거래량 순위를 실시간 인기 순위로 부르지 않는다. 종목별 가격 수준의 차이를 줄이는 거래대금 기준은 대안으로만 제안한다.
4. 장중 추정가 오차율을 전일 종가와 비교해 정확도라고 표시하지 않는다. 같은 시각·동일 KRX/NXT 세션의 기준 데이터가 있어야 정확한 오차 검증이 가능하다.
5. 인증키는 활용신청 후 서버 환경변수에만 보관한다. 새 키·계약은 아직 요청하거나 생성하지 않았다.

## 1,000명 확장성 설계 제안

일별 원천은 서버 수집 후 저장하고 사용자에게 저장된 결과를 제공한다. 1,000명의 5초 폴링을 공급자 API 1,000회 호출로 연결하지 않는다. 다중 인스턴스에서는 현재 프로세스 캐시만으로 충분하다고 보지 않고 공유 저장소·CDN 캐시·호출 제한을 검증한다. 공급자 이용료와 Oracle·DB·트래픽 비용은 따로 산정한다.
