# 대댓글 DB 적용 체크리스트

대상: `202609090002_community_replies.sql`. 기존 [원격 DB 적용 상태](./2026-09-08_원격_DB_적용상태.md)와 별개의 후속 변경이다. 이 문서 작성 자체가 원격 적용 완료를 뜻하지 않는다.

## 현재 경계

- 2026-09-09 사용자 승인 후 원격 적용 완료. 로컬 구현·검증·리뷰 및 백업·rollback 리허설을 먼저 수행했다.
- 원격 미적용 환경에서는 기존 댓글을 유지하며 대댓글 기능은 활성화하지 않는다.
- 기존 `community-retention-every-minute` 비활성 상태를 유지한다. 대댓글 도입은 자동 파기 활성화 승인이 아니다.
- `.env.local`·토큰·서비스 키를 공개 문서나 Git에 저장하지 않는다.

## 적용 전

- [x] 로컬 통합 테스트와 기능/권한 리뷰 통과. SQL 4개, 전체 644개 통과 / 24개 건너뜀. 미존재 RPC 판별 지적을 수정하고 재리뷰 통과.
- [x] 사용자에게 원격 적용 승인 확인.
- [x] 연결된 프로젝트가 의도한 프로젝트인지 비밀값 노출 없이 확인.
- [x] 원격 migration 이력이 `202609090001`까지인지 확인. 이력이 다르면 임의 repair/push 하지 않는다.
- [x] 기존 게시글·댓글 수, 공개 상태, 원문 변경 여부 비교에 필요한 기준값을 transaction의 임시 snapshot으로 확보.
- [x] 원격 스키마·데이터 백업을 Git 외부에 제한 권한으로 보관. 폴더 700·파일 600, 스키마 76,939 bytes·데이터 106,932 bytes. `public,supabase_migrations`만 포함하며 전체 Auth/Storage 백업·restore 검증은 아님. 파일 내용 미출력.
- [x] 단일 transaction rollback 리허설 통과. 기존 필드 동일·부모 null 확인, rollback 이후 최신 이력 090001·부모 열/함수 없음 별도 확인.

## 적용·확인

- [x] 대댓글 migration과 이력 기록을 함께 commit. 기존 글 2개·댓글 1개 내용 및 cron 설정 동일 검증. 보관 기간·cron 활성 상태 변경 없음.
- [x] 로컬 SQL 통합 검사에서 비공개 원댓글 원문·작성자 제거 확인. 원격은 공개 응답에 UUID·관리 사유 필드 없음 확인만 수행했고 실제 숨김 테스트는 하지 않음.
- [x] server-only RPC anon/authenticated 실행 불가·service_role 실행 가능 및 postgres owner 확인. PUBLIC grant 회수는 적용 SQL과 실효 권한 검사로 확인.
- [x] 새 부모 필드의 직접 클라이언트 INSERT/UPDATE 불가 권한 확인. 실제 거부 동작은 로컬 통합 테스트에서 확인.
- [x] schema cache 갱신 후 댓글 API HTTP 200·`repliesEnabled:true`·기존 댓글 1개 확인. 부모별 답글 조회 HTTP 200·0개 확인.
- [x] 사용자 화면에서 답글 버튼과 입력창·이모지·전송 버튼, 기존 댓글 정상 표시 확인.
- [x] 원격 테스트 글/댓글을 생성·숨김·삭제하지 않음. 실제 원격 전송 E2E는 이번 검증 범위 밖.
- [x] 실제 적용 결과·검증 범위·남은 항목을 이 문서와 제품 이력에 기록.

## 실패 대응

리허설 실패는 transaction rollback으로 끝내고 원인을 확인한다. 커밋 후 오류라면 앱의 새 답글 기능을 중지하고 기존 데이터 보존부터 확인한다. 부모 연결이 저장된 이후에는 migration을 무조건 되돌리거나 열을 삭제하지 않는다. 기존 댓글의 부모 연결·공개 상태를 보존하는 복구 계획을 세운 뒤 수행한다.
