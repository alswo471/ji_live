# 지투라이브 멀티자산 대시보드 1차 개편 설계

## 1. 목표

한국·미국 주식, 암호화폐와 핵심 시장 지표를 한 화면에서 확인하는 공개용 대시보드로 개편한다. 프리장, 정규장과 애프터장에서는 해당 세션의 실제 현재가를 우선하고, 시세가 제공되지 않는 시간·주말·공휴일에는 해외 연관 지표로 계산한 참고 추정가를 분명히 구분해 제공한다.

## 2. 범위

### 포함

- 한국 주식 대표 10종목
- 미국 주식 대표 10종목
- 암호화폐 5종목
- KOSPI, USD/KRW, NASDAQ 100 연동(QQQ), 금 연동(PAXG) 지표
- 프리장·정규장·애프터장·장 마감·참고 추정 상태 구분
- 종목 가격·거래량 상세 차트
- 한글명·영문명 종목 표기 전환
- 라이트·다크 테마 전환과 브라우저별 선택 유지
- 상위 100위 밖 종목의 실제 현재가·전일 종가 기반 등락률 보완
- 시세 공급자, 기준 시각, 추정 근거와 신뢰도 표시
- 공급자별 장애 격리와 재호출 제어

### 제외

- 로그인, 회원별 설정과 관심종목
- 토스증권 계좌, 보유종목, 평단가와 수익률
- 매매와 투자 알림
- 학습형 AI 예측 모델

## 3. 선택한 접근법

멀티소스 조합형을 사용한다. 하나의 API에 모든 자산을 의존하는 방식은 구현이 단순하지만 자산군별 정확도, 시장 세션, 호출 한도와 확장성을 동시에 만족시키기 어렵다. 유료 통합 시세는 초기 개인 학습 프로젝트에 비용과 라이선스 부담이 크다.

### 공급자 역할

| 자산 | 1차 공급자 | 역할 |
| --- | --- | --- |
| 한국 주식 | Toss Invest Open API | 종목 메타데이터와 지원되는 시장 세션의 실제 시세 |
| 글로벌 암호화폐 | Binance | 글로벌 기준 가격과 차트 데이터 |
| 원화 암호화폐 | Bithumb | KRW 기준 가격과 국내·글로벌 가격차 |
| 시장 지표·추정 프록시 | Toss, Binance | KOSPI, USD/KRW, QQQ 실제 시세, PAXG/USDT 실제 시세와 종목별 연관 지표 |

토스의 프리장·애프터장 지원 범위와 각 지표 공급자의 재배포 조건은 구현 전 공식 문서에서 다시 검증한다. 지원하지 않는 세션을 임의로 실시간으로 표시하지 않는다.

QQQ와 PAXG는 추정값이 아니라 해당 상품의 실제 거래값이다. 화면에서는 각각 `NASDAQ 100 연동(QQQ)`, `금 연동(PAXG)`으로 표시하고 NASDAQ 지수나 XAU/USD 현물처럼 표현하지 않는다. 이 상품의 실제 변동률은 한국 주식 참고 추정가의 입력으로 사용할 수 있다.

## 4. 공통 시세 모델

공급자별 응답을 `MarketQuote`로 변환한다. 화면은 공급자 원본 형식을 모르고 `MarketQuote`만 사용한다.

```ts
type MarketQuote = {
  symbol: string
  nameKo: string
  nameEn: string
  assetClass: 'kr-stock' | 'us-stock' | 'crypto' | 'index' | 'fx' | 'metal'
  price: number | null
  currency: 'KRW' | 'USD'
  changeRate: number | null
  tradingAmount: number | null
  asOf: string | null
  session: 'day' | 'pre' | 'regular' | 'after' | 'closed' | 'always-open'
  quality: 'realtime' | 'delayed' | 'estimated' | 'stale' | 'unavailable'
  provider: string | null
  confidence: 'high' | 'medium' | 'low' | null
  estimateInputs: string[]
}
```

종목명 전환은 전체 UI 번역이 아니다. 국내 주식, 미국 주식과 암호화폐 모두 `nameKo`와 `nameEn`을 갖고, 사용자가 선택한 표기만 목록·상세에 적용한다. 심볼이나 종목 코드는 항상 함께 표시한다.

## 5. 데이터 흐름

```text
외부 시세 공급자
→ 공급자별 adapter
→ MarketQuote 정규화
→ 시장 세션 판정
→ 실제 시세 우선 선택
→ 실제 시세가 없을 때만 추정 엔진 실행
→ 공급자별 TTL cache와 동시 요청 병합
→ dashboard API
→ 목록·상세·차트 UI
```

실제 시세가 존재하면 품질이 낮은 추정가로 대체하지 않는다. 공급자 장애 시 마지막 정상 데이터가 있으면 `stale`과 기준 시각을 표시하고, 데이터가 없으면 `unavailable`로 응답한다.

### 등락률 보완

토스 랭킹 API는 상위 100위까지만 제공하므로 랭킹 밖 종목은 `changeRate`와 `tradingAmount`가 없을 수 있다. 랭킹에서 등락률을 얻지 못한 주식은 토스 일봉 2개에서 전일 종가를 구하고 다음 식으로 실제 시세 기반 등락률을 계산한다.

```text
등락률 = 실시간 현재가 ÷ 전일 종가 - 1
```

전일 종가는 거래일 동안 변하지 않으므로 별도 장기 cache에 저장하고 5초 폴링마다 다시 요청하지 않는다. 계산한 등락률은 예측값이 아니므로 `참고 추정`으로 표시하지 않는다. 정확한 거래대금이 랭킹에 없으면 값을 만들어내지 않고 일봉 거래량을 대신 표시한다.

## 6. 참고 추정가

1차는 설명 가능한 가중평균 모델을 사용한다.

```text
추정 수익률 =
  해외 연관 상품 변동률 × 종목 민감도
  + 업종 지표 변동률 × 업종 민감도
  + USD/KRW 변동률 × 환율 민감도

참고 추정가 = 마지막 실제 기준가 × (1 + 추정 수익률)
```

종목별 mapping에는 연관 상품, 업종 지표, 환율 영향, 가중치와 적용 가능 시간을 정의한다. 예를 들어 삼성전자, SK하이닉스와 한미반도체는 검증된 반도체 지표, 한국 시장 ETF와 USD/KRW를 후보로 삼는다. 구체적 상품과 가중치는 과거 오차 검증 없이 임의로 확정하지 않는다.

신뢰도는 사용한 입력 수, 데이터 신선도, 누락된 입력과 과거 오차를 기준으로 `high`, `medium`, `low`로 계산한다. 추정가와 다음 실제 기준가의 오차를 누적해 후속 버전에서 가중치를 보정한다.

## 7. 화면 설계

선택한 방향은 라이트·다크를 지원하는 **하이브리드 마켓 콕핏**이다. 전문가용 터미널의 정보 밀도와 일반 사용자를 위한 요약의 균형을 맞춘다. UI/UX Pro Max의 금융 대시보드 조회 결과를 반영해 높은 대비, 밀도 높은 레이아웃, 절제된 모션과 금융 데이터에 적합한 서체를 사용한다. 첫 방문은 운영체제 테마를 따르고 사용자가 바꾸면 해당 브라우저에 저장한다.

### 화면 영역

1. 상단 상태 바: 한국·미국 시장 세션과 마지막 갱신 시각
2. 핵심 시장 지표: KOSPI, USD/KRW, NASDAQ 100 연동(QQQ), 금 연동(PAXG)
3. 자산 탭: 한국 주식, 미국 주식, 암호화폐
4. 종목 목록: 현재가, 등락률, 거래대금 또는 거래량, 시세 품질 배지
5. 종목 상세: Lightweight Charts 기반 가격·거래량 차트, 공급자와 상태
6. 추정 안내: 연관 지표, 기준 시각과 신뢰도를 점진적으로 펼쳐보는 영역

### 종목명 표기

- 화면 전체 언어는 한국어를 유지하고 `한글명 | 영문명` 토글은 종목명만 바꾼다.
- 국내 주식은 `삼성전자 · 005930` 또는 `Samsung Electronics · 005930`처럼 표시한다.
- 미국 주식은 `엔비디아 · NVDA` 또는 `NVIDIA · NVDA`처럼 표시한다.
- 암호화폐는 `비트코인 · BTC` 또는 `Bitcoin · BTC`처럼 표시한다.
- 선택값은 로그인 없이 브라우저에 저장하며 모든 목록과 상세 화면에서 동일하게 적용한다.

### 종목 상세와 차트

종목 행 전체를 클릭하면 `/market/[symbol]` 전용 상세 화면으로 이동한다. 별도 URL을 사용해 모바일의 자연스러운 뒤로가기, 새 탭과 공유 가능한 주소를 지원한다. 상세 화면은 다음 정보를 우선순위대로 제공한다.

1. 종목명, 심볼, 현재 시장 세션과 공급자
2. 5초 갱신 현재가, 실제 시세 기반 등락률과 기준 시각
3. 시가·고가·저가·전일 종가, 거래량과 제공 가능한 거래대금
4. `1일 | 1주 | 1개월` 기간 선택
5. Lightweight Charts 캔들 차트와 거래량 막대

주식 차트는 토스 1분봉·일봉, 글로벌 코인은 Binance klines, 원화 코인은 Bithumb candles를 공통 `{ time, open, high, low, close, volume }` 모델로 변환한다. `1일`은 1분봉을 페이지네이션해 최근 거래일 최대 500개, `1주`는 최근 일봉 7개, `1개월`은 최근 일봉 30개를 표시한다. 현재가와 등락률은 5초, 1분봉은 60초 단위로 갱신하며 일봉은 거래일 단위 cache를 사용한다. 차트를 받지 못해도 현재가 상세 정보와 오류 안내는 유지한다.

### 실시간 시각 피드백

- 한국 사용자에게 익숙한 상승 빨강, 하락 파랑, 보합 회색을 모든 자산군에 일관되게 적용한다.
- 가격 변경 시 상태 색 배경을 300–500ms 동안 은은하게 표시한 뒤 제거한다.
- `prefers-reduced-motion`에서는 점멸을 제거한다.
- 색만으로 상태를 구분하지 않고 `+`, `-`, 방향 아이콘과 스크린리더용 텍스트를 함께 제공한다.
- 추정가는 상승·하락색과 별개의 주황색 `참고 추정` 배지로 구분한다.

### 반응형과 접근성

- 375px, 768px, 1024px과 1440px에서 수평 스크롤 없이 핵심 정보를 사용할 수 있어야 한다.
- 모바일 목록에서는 거래대금처럼 중요도가 낮은 정보를 접고, 종목명·현재가·등락률·시세 상태를 우선한다.
- 모든 조작 요소는 키보드 포커스와 44px 이상의 터치 영역을 제공한다.
- 동적 시세 상태는 사용자의 읽기를 방해하지 않는 `aria-live="polite"`로 전달한다.
- 캔들 색만으로 OHLC를 구분하지 않고 tooltip과 요약 텍스트를 제공한다.
- 종목 행은 링크 의미와 키보드 탐색을 제공하고 테마·언어 토글은 최소 44px 조작 영역을 유지한다.

## 8. 캐시와 장애 처리

- 공급자별로 독립된 호출 주기, TTL cache, 동시 요청 병합과 재호출 제한을 둔다.
- 전일 종가와 일봉은 거래일 단위, 1분봉은 60초 단위로 cache해 차트 추가가 429를 재발시키지 않게 한다.
- 429 또는 연속 실패 시 해당 공급자만 짧은 시간 요청을 차단하고 다른 자산군을 유지한다.
- 사용 가능한 최신 데이터와 마지막 수신 시각을 함께 표시한다.
- 실제 시세 실패를 사용자에게 알리지 않고 추정가로 조용히 대체하지 않는다.
- 로그에는 공급자, 상태 코드, 실패 분류와 재시도 가능 시각만 남기고 비밀키나 개인 정보는 기록하지 않는다.

## 9. 검증

### 자동 검증

- 프리장, 정규장, 애프터장, 장 마감과 주말 세션 판정
- 실제 시세의 추정가 우선순위
- 추정 수익률과 신뢰도 계산
- 상승·하락·보합 색상과 부호 바인딩
- 429, timeout, 잘못된 응답과 일부 공급자 장애
- cache TTL과 동시 요청 병합
- 랭킹 포함 종목의 직접 등락률과 랭킹 밖 종목의 전일 종가 계산 등락률
- 한글명·영문명과 라이트·다크 선택 유지
- 상세 route의 주식·코인 candle 정규화와 미지원 상태

### 수동 검증

- 375px, 768px, 1024px과 1440px 화면
- 키보드 탐색, 포커스 표시와 텍스트 대비
- 일반 모션과 `prefers-reduced-motion`
- 실제 시세, 지연 시세, stale, 추정가와 미제공 상태
- 목록에서 상세 화면 이동, 브라우저 뒤로가기와 기간 선택
- 로컬과 Oracle 배포 환경의 API 호출 제한과 cache
