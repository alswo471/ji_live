# 지투라이브 차트 주기·시장 지표 보완 설계

## 목표

종목 상세 차트를 국내 증권 앱에서 익숙한 봉 단위로 확장하고, 테마 전환 뒤 차트가 사라지는 문제와 KOSPI·USD/KRW의 불명확한 등락 표시를 해결한다. 공개 배포 정보는 Oracle 배포가 완료되기 전까지 문서에 노출하지 않는다.

## 범위

- 차트 주기: `1분`, `15분`, `1시간`, `4시간`, `일봉`, `주봉`, `월봉`
- 기본 표시 범위: 최근 2시간, 1일, 5일, 1개월, 6개월, 2년, 10년
- 주기별 시간축 형식과 초기 viewport
- 라이트·다크 전환 시 기존 차트와 candle 유지
- Toss KOSPI 일봉 전일 종가 기반 실제 등락률
- Toss USD/KRW가 제공하는 상승·하락·보합 방향 표시
- README의 기존 OpenAI Sites URL과 Hosting 설명 제거

## 데이터 계약

`CandleRange`를 실제 봉 단위를 나타내는 `CandleInterval`로 교체한다.

```ts
type CandleInterval = '1m' | '15m' | '1h' | '4h' | '1d' | '1w' | '1M'
```

대소문자를 구분해 `1m`은 1분, `1M`은 월봉으로 사용한다. API도 `range` 대신 `interval` query parameter를 사용하며, 잘못된 값은 400으로 거절한다.

## 공급자별 candle 처리

| 화면 주기 | Toss 원본 | Binance | Bithumb |
| --- | --- | --- | --- |
| 1분 | 1분봉 | 1분봉 | 1분봉 |
| 15분 | 1분봉 합산 | 15분봉 | 15분봉 |
| 1시간 | 1분봉 합산 | 1시간봉 | 1시간봉 |
| 4시간 | 1분봉 합산 | 4시간봉 | 4시간봉 |
| 일봉 | 일봉 | 일봉 | 일봉 |
| 주봉 | 일봉 합산 | 주봉 | 주봉 |
| 월봉 | 일봉 합산 | 월봉 | 월봉 |

Toss는 공식적으로 1분봉과 일봉만 제공하므로 서버에서 OHLCV를 합산한다. 합산 봉의 시가는 첫 봉, 고가는 최댓값, 저가는 최솟값, 종가는 마지막 봉, 거래량은 합계로 계산한다. 주봉과 월봉은 거래소 현지 날짜를 기준으로 묶는다.

상세 페이지 최초 요청량이 커질 수 있는 4시간·주봉·월봉은 긴 cache를 적용하고 같은 요청은 하나로 병합한다. 4시간봉은 요청당 최대 40페이지·10초 예산과 30분 cache를 적용하며, 공개 Oracle 배포 전 공유 cache 또는 사전 집계를 추가한다. 공급자 호출 제한이나 장애가 발생하면 실패 응답을 공개 cache에 저장하지 않고 가격 상세 화면은 유지하며 차트 영역에만 오류 상태를 표시한다.

KOSPI 차트는 일반 종목 candle endpoint가 아니라 Toss의 시장 지표 candle endpoint를 사용한다.

## 차트 UI

- 7개 주기 버튼은 모바일에서 가로 스크롤할 수 있는 tablist로 제공한다.
- 기본 선택은 `1분`이다.
- 서버가 반환한 데이터 중 승인된 기간만 초기 viewport에 표시한다.
- 1분·15분·1시간·4시간은 시간 중심, 일봉은 날짜, 주봉은 연·월, 월봉은 연도 중심으로 하단 축을 표시한다.
- 사용자가 확대·축소하거나 이동한 뒤에는 데이터 갱신만으로 viewport를 매번 초기화하지 않는다. 주기를 바꿀 때만 해당 기본 범위를 적용한다.
- 차트 인스턴스는 컴포넌트 생명주기 동안 한 번만 생성한다. 테마 전환은 `applyOptions`로 색상만 바꿔 candle 데이터와 사용자 viewport를 보존한다.

## 시장 지표 등락률

### KOSPI

Toss 시장 지표 일봉에서 전일 종가를 읽고 다음 식으로 계산한다.

```text
(현재 KOSPI - 전일 종가) / 전일 종가
```

계산값은 추정값이 아니며 `previous-close` 출처로 기록한다. 전일 종가는 거래일 단위로 cache한다.

### USD/KRW

Toss 환율 응답은 현재 환율과 `UP`, `DOWN`, `EQUAL` 방향을 제공하지만 전일 숫자값은 제공하지 않는다. 서로 다른 공급자의 현재가와 일간 기준환율을 섞어 실시간 등락률처럼 보이게 하지 않는다.

- 현재 환율은 Toss 실제값을 유지한다.
- 퍼센트 대신 Toss의 방향을 `상승`, `하락`, `보합`으로 표시한다.
- 보조 문구로 `토스증권 실시간 · 등락폭 미제공`을 표시한다.
- 향후 동일 공급처의 실시간 FX candle 또는 전일 종가 저장소가 준비되면 퍼센트로 교체한다.
