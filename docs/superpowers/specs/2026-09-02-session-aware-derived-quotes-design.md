# 지투라이브 세션 인식 한국 주식 추정가 개편 설계

## 1. 문서 목적

이 문서는 공개·광고형 서비스에서 증권사 개인용 API와 무단 수집에 의존하지 않으면서 한국 주식의 24시간 참고 추정가, 상세 OHLC, 차트와 추종상품 거래량을 제공하기 위한 설계를 정의한다.

기존 `0.4.0` 구조의 장점인 공개 API 기반 확장성과 실제값·추정값 구분 원칙은 유지한다. 다만 모든 시간대를 `always-open`, 모든 등락률을 `공급자 24시간 전 대비`로 처리하고 한국 주식 차트를 차단한 한계를 보완한다.

## 2. 기획 배경

### 2.1 해결하려는 사용자 문제

- 국내 정규장이 끝나면 일반 증권 화면의 한국 주식 가격이 멈춘다.
- 해외 파생시장은 계속 움직이므로 다음 국내 시장의 기대를 참고할 수 있지만 실제 주식 체결가와는 성격이 다르다.
- 사용자는 프리마켓, KRX 정규장, NXT 애프터마켓과 휴장 시간을 구분하면서 하나의 화면에서 흐름을 보고 싶다.
- 상세 화면에 시가·고가·저가·거래량과 차트가 없으면 가격의 움직임과 근거를 검증하기 어렵다.

### 2.2 공개 서비스 제약

- Toss Invest 등 증권사 API는 개인 계좌·고정 IP 기반 사용에는 적합하지만 공개 방문자에게 시세를 재배포하고 광고 수익을 붙이는 서비스의 기본 공급자로 채택하지 않는다.
- KRX 실시간·20분 지연·종가 정보를 재배포하거나 수익사업에 사용하려면 별도 정보이용 계약이 필요하다.
- KRX Open API는 비상업적 이용으로 제한되므로 광고형 공개 서비스의 계산 입력으로 사용하지 않는다.
- 금융위원회 공공데이터의 주식 시세정보는 이용허락 범위 제한이 없지만 영업일 다음 날 오후에 갱신되므로 실시간 공급자가 아니라 확정 데이터 검증 후보로만 취급한다.
- NXT 공식 웹사이트의 개별 종목 정보는 20분 지연이며, 공개 화면을 크롤링해 서비스 데이터로 재배포하지 않는다.
- TradingView 위젯 데이터는 표시용이며 추출·재가공하거나 내부 계산 입력으로 사용하지 않는다.

## 3. 현재 구조와 확인된 문제

### 3.1 현재 계산

```text
한국 주식 현재 추정가
= 해외 파생상품 가격(markPx 또는 lastPrice)
× Bithumb KRW-USDT 합성환율

현재 등락률
= 해외 파생상품 공급자의 24시간 등락률
```

### 3.2 현재 구조가 잘하는 것

- Hyperliquid의 `xyz:SMSN`처럼 KRX 기초자산을 참조하는 상품은 KRX 정규장 가격에 비교적 가깝게 움직인다.
- API 키가 없는 공개 공급자를 서버 cache 뒤에 두어 방문자 수와 공급자 호출 수를 분리할 수 있다.
- 정규장 이후와 주말에도 공급자가 거래되는 동안 가격이 갱신된다.
- 화면에서 실제 주식 체결가가 아닌 `24시간 추정가`로 명시한다.

### 3.3 확인된 문제

1. `session: always-open`이므로 프리·정규·애프터·휴장을 구분하지 못한다.
2. 공급자의 24시간 등락률은 국내 전일 종가 대비 등락률과 기준이 다르다.
3. 한국 주식 candle 요청을 의도적으로 차단해 차트와 OHLC·거래량이 모두 비어 있다.
4. 현재가와 NXT 공개값을 비교하면 별도 주문장 차이와 20분 지연이 동시에 섞인다.
5. 같은 시각의 실제 기준값과 비교한 오차 기록이 없어 정확도를 설명할 수 없다.
6. 파생상품 거래량을 실제 KRX 거래량으로 오인할 수 있어 명확한 단위·성격 표기가 필요하다.

## 4. 선택한 접근법

### 4.1 선택: 세션 인식 파생 추정가와 검증 계층

현재의 공개 파생상품 기반 가격 엔진은 유지하되 다음 계층을 추가한다.

1. 한국 시장 세션 판별
2. 국내 기준 대비값과 공급자 24시간 대비값 분리
3. 파생 candle과 시점별 환율 candle을 결합한 원화 추정 candle
4. 추종상품 거래량과 국내 실제 거래량의 의미 분리
5. 동일 시각 기준 오차 측정과 신뢰도 산정
6. 공급자·시장 세션·기준 시각·가격 성격 표시

### 4.2 제외한 접근법

#### 증권사 API를 공개 시세 공급자로 사용

실제 체결가와 계좌 기능에는 유리하지만 공개 재배포·광고 서비스의 권리와 확장성 조건이 확인되지 않아 제외한다.

#### Naver Finance 또는 NXT 웹 화면 크롤링

빠르게 실제값을 얻을 수 있어 보여도 공식 API 계약이 아니며 화면 구조 변경, 차단과 재배포 권리 문제가 있으므로 제외한다.

#### 현재 추정가를 NXT 가격에 항상 보정

Hyperliquid 한국 주식 상품은 KRX 기초자산을 참조한다. KRX와 NXT는 별도 주문장이므로 NXT에 강제로 맞추면 정규장 KRX 추종 정확도가 오히려 나빠질 수 있다.

## 5. 기준 시장과 세션

`Asia/Seoul` 시간대와 영업일 달력을 기준으로 다음 상태를 계산한다.

| 구간 | 시간 | 기준 시장 | 대표 문구 |
| --- | --- | --- | --- |
| 야간 | 00:00~08:00 | 실제 국내시장 없음 | `야간 추정가` |
| NXT 프리 | 08:00~08:50 | NXT | `프리마켓 추정가` |
| 시가 단일가 | 08:50~09:00 | KRX 시가 형성 | `시가 형성 중` |
| KRX 정규 | 09:00~09:00:30 | KRX | `정규장 추정가` |
| 동시 거래 | 09:00:30~15:20 | KRX 대표, NXT 비교 | `정규장 추정가` |
| KRX 종가 구간 | 15:20~15:30 | KRX | `종가 형성 중` |
| 전환 구간 | 15:30~15:40 | NXT 호가·KRX 종가 | `애프터 전환 중` |
| NXT 애프터 | 15:40~20:00 | NXT | `애프터마켓 추정가` |
| 휴장 | 20:00 이후·주말·공휴일 | 실제 국내시장 없음 | `휴장 중 추정가` |

휴장일 정보가 없거나 확인되지 않으면 영업일이라고 추측하지 않고 `closed` 또는 `unknown` 성격의 보수적인 안내를 사용한다. 초기 구현은 주말과 정적 휴장일 목록을 지원하고, 운영 가능한 공식 달력 공급자가 확인되면 교체한다.

## 6. 가격 알고리즘

### 6.1 기본 원화 추정가

```text
rawEstimatedKrw(t)
= derivativePrice(t) × syntheticKrwPerUsd(t)
```

- Hyperliquid: `markPx`
- Binance Futures: `lastPrice`
- 환율: Bithumb `KRW-USDT`
- 모든 입력의 통화·계약 단위와 최신성을 검증한다.
- 원화 표시 전에 국내 주식 호가 단위로 반올림한다.

### 6.2 기준점 보정

합법적으로 사용할 수 있는 동일 종목의 확정 실제 종가와 해당 시각의 파생·환율 데이터를 확보한 경우에만 보정계수를 계산한다.

```text
calibrationFactor(d)
= verifiedCloseKrw(d)
/ (derivativePrice(d, closeTime) × syntheticFx(d, closeTime))

calibratedEstimate(t)
= rawEstimatedKrw(t) × calibrationFactor(d)
```

안전 규칙:

- 실제 종가의 사용 권리·기준일·시장·종목 mapping이 검증되지 않으면 보정하지 않는다.
- 보정계수는 미래 실제값을 과거 차트에 적용하지 않는다.
- 보정계수가 급변하거나 허용 범위를 벗어나면 해당 종목의 신뢰도를 낮추고 raw 추정가를 유지하거나 미제공 처리한다.
- 정규장 raw 추정가가 KRX에 안정적으로 가까운 종목은 무조건 보정하지 않는다. 백테스트로 지속적인 편향이 확인된 경우에만 제한적으로 사용한다.

### 6.3 등락률

두 값을 서로 덮어쓰지 않고 별도로 모델링한다.

```text
provider24hRate
= 공급자가 제공한 24시간 등락률

domesticReferenceRate
= currentEstimatedKrw / verifiedDomesticReference - 1
```

- 국내 기준값을 합법적으로 확보하지 못한 상태에서는 `국내 전일 종가 대비`라고 표시하지 않는다.
- 그 경우 공급자 24시간 대비값을 유지하되 문구를 정확히 표시한다.
- 추정 전일 종가를 사용하는 경우 `전일 추정 종가 대비`로 별도 표기한다.

## 7. 한국 주식 원화 추정 candle

### 7.1 입력

- 종목 파생 candle: Hyperliquid candle snapshot 또는 Binance futures klines
- 환율 candle: Bithumb `KRW-USDT`
- 주기: `1m`, `15m`, `1h`, `4h`, `1d`, `1w`, `1M`

### 7.2 시간 정렬

각 파생 candle에는 같은 bucket의 환율 candle을 결합한다. 해당 시점의 환율이 없으면 가장 가까운 과거 값만 제한된 허용 시간 안에서 사용하며 미래 환율로 과거 값을 채우지 않는다.

```text
openKrw  = derivativeOpen  × fxOpen
highKrw  = max(
  derivativeHigh × fxHigh,
  derivativeHigh × fxLow,
  derivativeLow  × fxHigh,
  derivativeLow  × fxLow
)
lowKrw   = min(같은 네 조합)
closeKrw = derivativeClose × fxClose
```

두 자산의 고가 발생 시각이 다르기 때문에 단순 `high × high`는 실제 동시 가격보다 과대 추정될 수 있다. 초기 구현은 candle 내부의 보수적 범위임을 문서화하고, 1분 원시 봉을 먼저 원화 환산한 뒤 상위 봉을 집계해 오차를 줄인다.

### 7.3 거래량

- Hyperliquid와 Binance가 제공한 파생상품 수량 또는 명목 거래대금만 사용한다.
- 화면 라벨은 `추종상품 거래량` 또는 `추종상품 거래대금`으로 표시한다.
- KRX·NXT 실제 주식 거래량으로 표현하지 않는다.
- 공급자 계약 단위가 검증되지 않으면 수량 대신 명목 거래대금을 우선한다.

## 8. 정확도와 신뢰도

### 8.1 올바른 오차 계산

20분 지연 실제값을 현재 추정가와 비교하지 않는다. 동일 시각 snapshot끼리 비교한다.

```text
absolutePercentageError(t)
= abs(estimated(t) - actual(t)) / actual(t)
```

### 8.2 수집 지표

- 세션별 중앙 절대백분율오차(MdAPE)
- 95백분위 절대백분율오차(P95 APE)
- 상승·하락 방향 일치율
- 데이터 최신성
- 공급자 간 가격 차이
- 다음 실제 개장가 대비 야간·주말 마지막 추정가 오차

### 8.3 출시 합격선

다음 값은 현재 정확도를 주장하는 수치가 아니라 종목 노출 여부를 결정하는 목표다.

| 세션 | MdAPE 목표 | P95 APE 목표 |
| --- | ---: | ---: |
| NXT 프리 | 1.0% 이하 | 3.0% 이하 |
| KRX 정규 | 0.5% 이하 | 1.5% 이하 |
| NXT 애프터 | 1.0% 이하 | 3.0% 이하 |

야간·주말에는 동시 실제가격이 없으므로 실시간 오차율을 만들지 않는다. 다음 실제 개장가와 비교한 예측 오차로 평가한다.

### 8.4 신뢰도

- `high`: 세션별 목표 통과, 입력 최신, mapping·단위 검증 완료
- `medium`: 목표 일부 미달 또는 실제 기준 데이터 부족
- `low`: P95 목표 초과, 공급자 간 괴리, 유동성 부족
- `unavailable`: stale 한계 초과, 단위 미검증, 가격 범위 오류

최소 20거래일을 1차 판정 기간으로 사용하고, 60거래일 이후 종목 확대 여부를 결정한다.

## 9. 데이터 모델 변경안

기존 필드의 의미를 바꾸지 않고 필요한 상태를 추가한다.

```ts
type KrMarketSession =
  | 'overnight'
  | 'nxt-pre'
  | 'krx-opening-auction'
  | 'krx-regular'
  | 'krx-nxt-overlap'
  | 'krx-closing-auction'
  | 'nxt-transition'
  | 'nxt-after'
  | 'closed'

type ComparisonBasis =
  | 'provider-24h'
  | 'verified-domestic-close'
  | 'estimated-domestic-close'
  | null

type VolumeKind =
  | 'underlying-shares'
  | 'derivative-contracts'
  | 'derivative-notional'
  | null
```

시세와 candle 응답에 다음 근거를 함께 전달한다.

- 기준 시장과 세션
- 가격 종류
- 비교 기준
- 거래량 종류와 단위
- 공급자와 공급자 심볼
- 가장 오래된 입력 기준 시각
- 보정 적용 여부와 기준일
- 신뢰도와 저하 사유

## 10. UI 원칙

### 목록

- 가격 배지: `24시간 추정가`
- 세션 배지: `정규장 추정`, `프리마켓 추정`, `애프터마켓 추정`, `휴장 중 추정`
- 등락률 아래 비교 기준을 짧게 표시한다.
- KRX와 NXT 실제값을 가지고 있지 않으면 `실시간 KRX`, `실시간 NXT`라고 쓰지 않는다.

### 상세

- 추정 OHLC와 추종상품 거래량·거래대금을 제공한다.
- 차트 상단에 파생 공급자와 환산 근거를 표시한다.
- 실제 국내 거래량과 추종상품 거래량의 차이를 안내한다.
- 데이터가 없으면 고정 예시 숫자 대신 원인을 포함한 미제공 상태를 표시한다.
- 신뢰도는 색뿐 아니라 텍스트와 근거로 설명한다.

## 11. 장애와 경계 조건

- 환율만 실패: 한국 주식 원화 추정가·차트만 stale 또는 unavailable
- 한 파생 공급자 실패: 해당 공급자 종목만 격리
- candle 부분 누락: 불완전 bucket을 제거하거나 명시적으로 표시
- 429: `Retry-After`, 지수 백오프, 공급자별 회로 차단 유지
- 거래정지·VI·가격제한: 파생가격과 실제 국내가격의 괴리가 커질 수 있으므로 신뢰도 하향
- 서머타임: 한국 시장 세션에는 영향이 없지만 해외 공급자 candle 기준 시각을 UTC로 정규화
- 휴장일 미확인: 정상 영업으로 추측하지 않고 제한된 안내 제공

## 12. 테스트 전략

### 단위 테스트

- KST 경계 시각별 세션 판별
- 주말·휴장일 판별
- 파생가격·환율의 원화 환산과 호가 단위 반올림
- 공급자 24시간 대비와 국내 기준 대비의 분리
- 1분 원화 candle 변환과 상위 주기 집계
- 환율 candle 누락·stale 처리
- 거래량 종류와 통화 보존
- 보정계수 적용·미적용·이상값 차단

### 통합 테스트

- 한국 주식 candle API가 OHLC·거래량과 근거를 반환
- 상세 UI가 실제값·추정값·미제공을 구분
- 공급자 하나의 장애가 다른 자산군을 막지 않음
- cache와 동시 요청 병합이 공급자 호출량을 방문자 수와 분리

### 수동 검증

- 같은 시각의 저장된 추정가와 KRX/NXT 기준값 비교
- 375px·768px·1440px, 라이트·다크 모드
- 프리·정규·애프터 경계 전환
- 실제 주문 화면과 비교하되 동일성을 제품 보장으로 표현하지 않음

## 14. 성공 기준

- 정규장 현재가가 기존 KRX 추종 특성을 불필요하게 훼손하지 않는다.
- 한국 주식 상세에 추정 OHLC·차트와 추종상품 거래량이 표시된다.
- 등락률의 기준이 UI와 API에서 일치한다.
- KRX와 NXT를 별도 시장으로 설명하고 시간대별 기준을 구분한다.
- 20분 지연값과 현재값을 섞어 오차율을 만들지 않는다.
- 지원하지 않거나 검증되지 않은 값은 숫자를 만들지 않는다.
- Toss 자격증명 없이 전체 테스트와 build가 통과한다.

## 15. 후속 의사결정

- 실제 전일 종가 공급자의 상업적 이용 권리와 갱신 시각 확인
- 20분 지연 실제값을 사이트에 표시하려면 KRX·코스콤 또는 승인 벤더 계약 검토
- 20·60거래일 정확도 결과에 따른 종목 유지·제외
- Redis 또는 영속 시계열 저장소 도입은 오차 snapshot 규모가 메모리 cache 범위를 넘을 때 결정
