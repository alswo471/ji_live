# 지투라이브 공개용 24시간 파생 추정가 설계

## 1. 목표

공개 배포판에서 Toss Invest 시세 의존성을 제거하고, 한국 주식과 미국 주식을 해외 거래소의 토큰화 주식 무기한선물·파생상품으로 추종하는 24시간 참고 대시보드로 전환한다. 사용자가 KRX·미국 거래소의 실제 체결가로 오인하지 않도록 가격 성격, 비교 기준, 공급자와 기준 시각을 항상 함께 표시한다.

이 설계는 코루라이브의 제품 원리처럼 정규장에는 파생 가격이 기초자산 가격에 가까워지고, 장 종료 후에는 해외 파생시장의 기대를 반영해 가격이 계속 움직이는 구조를 채택한다. 구현과 문구를 그대로 복제하거나 코루라이브 내부 API에 의존하지 않고 공식 공개 API만 직접 사용한다.

## 2. 선택한 접근법

검토한 선택지는 다음 세 가지다.

1. **해외 파생상품 기반 24시간 추정가 — 선택**
   - 초기 비용과 동시접속자 증가에 대한 서버 부담이 낮다.
   - 장 종료 후에도 가격이 움직인다.
   - 실제 주식 체결가가 아니므로 일관된 추정가 표시가 필요하다.
2. **Toss Invest 시세를 공개 사이트에 재배포 — 제외**
   - 개인 학습과 내부 이용에는 유용하지만 사전 서면동의 없는 제3자 재배포·상업적 이용에 적합하지 않다.
3. **KRX·코스콤 실시간 정보이용계약 — 후속 선택지**
   - 실제 KRX 체결가를 제공하는 정석적인 방법이다.
   - 계약·비용·운영 요건을 확인한 뒤 별도 실제값 공급자로 추가한다.

## 3. 범위

### 포함

- Hyperliquid HIP-3 공개 API의 한국 주식 연동 파생상품
- Binance 공개 선물 API의 토큰화 주식 무기한선물
- Bithumb `KRW-USDT`를 활용한 원화 환산용 합성환율
- Bithumb 원화 암호화폐와 Binance PAXG 실제 거래상품
- 파생 추정가, 실제 거래상품과 데이터 미제공 상태의 명시적 구분
- 공급자별 cache, 동시 요청 병합, 장애 격리와 마지막 기준 시각
- 공개 배포판에서 Toss 환경변수·호출 경로·개인 계좌 기능 제거

### 제외

- KRX·NXT 실제 실시간 체결가라고 표시하는 기능
- Toss Invest 시세를 공개 방문자에게 전달하는 기능
- 코루라이브 Cloudflare Worker 또는 비공개 계산 기준 사용
- 지원 여부를 확인하지 않은 종목의 추정가 생성
- 자동매매, 매수·매도 신호와 가격 정확도 보장
- TradingView 차트 교체와 고급 그리기 도구 확장

## 4. 데이터 공급자와 종목

### 한국 주식 추정가

1차에는 공개 API에서 실제 응답을 검증한 심볼만 사용한다.

| 표시 종목 | 국내 코드 | 공급자 심볼 | 현재 추정가 계산 |
| --- | --- | --- | --- |
| 삼성전자 | `005930` | Hyperliquid `xyz:SMSN` | `markPx × 합성환율` |
| SK하이닉스 | `000660` | Hyperliquid `xyz:SKHX` | `markPx × 합성환율` |
| 현대차 | `005380` | Hyperliquid `xyz:HYUNDAI` | `markPx × 합성환율` |
| 삼성전기 | `009150` | Binance `SAMSUNGEMUSDT` | `lastPrice × 합성환율` |
| NAVER | `035420` | Binance `NAVERUSDT` | `lastPrice × 합성환율` |
| 한미반도체 | `042700` | Binance `HANMIUSDT` | `lastPrice × 합성환율` |
| LG전자 | `066570` | Binance `LGELECTRONICSUSDT` | `lastPrice × 합성환율` |

`markPx`와 `lastPrice`는 해당 해외 파생상품의 거래 단위가 USD·USDT 기준이라는 전제에서 원화로 환산한다. 공급자 응답의 통화·계약 명세가 이 전제와 맞지 않으면 해당 종목을 노출하지 않는다.

기존 한국 주식 10종목 중 검증된 파생상품이 없는 삼성바이오로직스, LG에너지솔루션, 기아, 셀트리온, 한화에어로스페이스와 두산에너빌리티는 1차 공개 목록에서 제외한다. 새로운 파생 심볼은 실제 API 응답, 계약 명세와 가격 범위를 검증한 뒤 추가한다.

### 미국 주식 추정가

기존 미국 주식 중 2026-09-01 Binance 선물 ticker 응답이 확인된 종목을 먼저 전환한다.

| 표시 종목 | 공급자 심볼 | 가격 표시 |
| --- | --- | --- |
| Tesla | `TSLAUSDT` | USDT 기준 무기한선물 가격 |
| NVIDIA | `NVDAUSDT` | USDT 기준 무기한선물 가격 |
| Apple | `AAPLUSDT` | USDT 기준 무기한선물 가격 |
| Alphabet A | `GOOGLUSDT` | USDT 기준 무기한선물 가격 |

미국 주식 화면도 `실제 미국 주식`이 아니라 `24시간 파생 추정가`로 표시한다. Microsoft, Amazon, Meta, Broadcom, AMD와 Netflix는 다른 공식 공개 공급자 mapping을 검증할 때까지 1차 목록에서 제외한다.

### 그 밖의 자산

| 자산 | 공급자 | 데이터 성격 |
| --- | --- | --- |
| 원화 암호화폐 | Bithumb | 실제 거래상품 |
| 글로벌 암호화폐·PAXG | Binance | 실제 거래상품 |
| 원화 환산 | Bithumb `KRW-USDT` | 은행 고시환율이 아닌 합성환율 |
| 미국 토큰화 주식 | Binance | 실제 미국 주식이 아닌 무기한선물 추정가 |
| 차트 | 기존 Lightweight Charts | 공급자 candle 데이터가 있는 자산만 제공 |

미국 토큰화 주식은 위 표의 검증된 종목만 전환한다. 검증되지 않은 기존 미국 주식은 값을 만들지 않고 목록에서 제외한다.

## 5. 공통 모델

기존 `MarketQuote`에 가격 성격과 비교 기준을 명시하는 필드를 추가한다.

```ts
type PriceKind = 'actual-product' | 'derived-estimate' | 'unavailable'
type ComparisonBasis = 'provider-24h' | 'previous-close' | null

type MarketQuote = {
  // 기존 필드
  priceKind: PriceKind
  comparisonBasis: ComparisonBasis
  sourceLabel: string | null
}
```

- `actual-product`: Bithumb 코인, Binance PAXG처럼 표시된 상품 자체의 실제 거래가
- `derived-estimate`: 토큰화 주식 파생가격을 원화로 환산한 참고 추정가
- `unavailable`: 공급자 또는 검증된 mapping이 없어 가격을 만들 수 없는 상태
- `provider-24h`: 공급자가 제공한 24시간 전 대비
- `previous-close`: 라이선스가 확인된 전일 종가 공급자가 추가된 이후에만 사용

한국 주식 파생 추정가의 1차 등락률은 임의 KRX 종가를 섞지 않고 공급자의 24시간 변동률을 사용한다. 따라서 화면 문구는 `24시간 전 대비`로 고정한다. 추후 합법적인 KRX 종가 공급자를 추가하면 별도의 `정규장 마감 대비` 값을 제공하되 기존 24시간 변동률을 조용히 덮어쓰지 않는다.

## 6. 데이터 흐름

```text
Hyperliquid metaAndAssetCtxs ─┐
                              ├─ 공급자 adapter ─┐
Binance futures ticker ───────┤                  │
                                                 ├─ quote composer
Bithumb KRW-USDT ─ 합성환율 ─────────────────────┘
                                                        │
                                                        ├─ cache / 장애 격리
                                                        ├─ dashboard API
                                                        └─ 목록·상세 UI
```

1. Hyperliquid와 Binance 요청을 병렬 실행한다.
2. Bithumb `KRW-USDT` 가격을 원화 환산값으로 사용한다.
3. 공급자 가격과 합성환율이 모두 정상 범위일 때만 한국 주식 추정가를 계산한다.
4. 한 입력이라도 없거나 오래됐으면 이전 값을 실제값처럼 유지하지 않고 `stale` 또는 `unavailable`로 표시한다.
5. 한국 주식 추정가는 정규장 중에도 항상 `derived-estimate`를 유지한다. 실제 KRX 가격과 가까워져도 배지를 `실시간`으로 바꾸지 않는다.

## 7. 화면 표시 원칙

- 한국 주식 가격 위 또는 옆에 주황색 `24시간 추정가` 배지를 항상 표시한다.
- 보조 문구는 `해외 파생상품 기준 · 24시간 전 대비`로 표시한다.
- 상세 화면에는 공급자를 `Hyperliquid 파생상품` 또는 `Binance 무기한선물`로 표시한다.
- 합성환율을 사용한 경우 `USDT/KRW 환산`을 계산 근거에 포함한다.
- 정규장 중 실제 KRX 가격과 같아 보여도 `실시간 KRX`, `실제 주가`라는 문구를 사용하지 않는다.
- 데이터 실패 시 기존 숫자를 새 값처럼 보이지 않게 마지막 수신 시각과 `갱신 지연`을 함께 표시한다.
- 상승 빨강·하락 파랑은 유지하되 배지, 부호와 설명 문구로 가격 성격과 방향을 색 외 방식으로도 전달한다.
- 사이트 하단과 상세 화면에 `실제 주식 가격이 아닌 해외 파생상품 기반 참고 추정가`라는 면책 문구를 제공한다.

## 8. cache와 확장성

- Hyperliquid·Binance·Bithumb 시세 cache TTL은 5초로 시작한다.
- 같은 cache miss에 대한 동시 요청은 하나로 병합한다.
- 브라우저 수와 외부 API 호출 수를 분리하고 dashboard API가 cache된 snapshot을 배포한다.
- 429 응답은 `Retry-After`를 우선하고 없으면 지수 백오프를 적용한다.
- 공급자별 회로 차단을 유지해 하나의 장애가 전체 대시보드를 막지 않게 한다.
- API 키가 필요 없는 공개 endpoint만 사용하고 브라우저에는 비밀값을 전달하지 않는다.

## 9. 차트 처리

- Hyperliquid는 공식 candle snapshot API에서 제공되는 주기만 사용한다.
- Binance 토큰화 주식은 선물 klines를 사용한다.
- 기존 7개 주기 중 공급자가 제공하지 않는 주기는 검증된 하위 봉 집계로만 만든다.
- 목록의 현재 추정가와 차트 마지막 candle의 공급자·통화 기준이 다르면 차트를 숨기고 이유를 표시한다.
- TradingView 고급 위젯과 그리기 도구 도입은 별도 설계로 진행한다.

## 10. 오류와 검증

### 자동 검증

- Hyperliquid `metaAndAssetCtxs` 응답 정규화
- Binance 선물 ticker 응답 정규화
- 합성환율을 적용한 KRW 추정가와 비정상 가격 범위 차단
- 파생 추정가가 모든 시장 세션에서 `derived-estimate`를 유지하는지 확인
- `provider-24h`와 `previous-close` 문구가 섞이지 않는지 확인
- 부분 공급자 장애, timeout, 429와 stale 처리
- 지원하지 않는 종목이 임의 가격을 만들지 않는지 확인
- Toss 자격증명 없이 dashboard와 build가 동작하는지 확인

### 수동 검증

- 실제 증권사 화면과 비교해 정규장 중 가격 차이를 관찰하되 동일성을 성공 기준으로 삼지 않는다.
- 장 종료 후에도 추정가와 기준 시각이 갱신되는지 확인한다.
- 라이트·다크, 375px·768px·1440px에서 배지와 면책 문구를 확인한다.
- 공급자 하나를 의도적으로 실패시켜 다른 자산군이 유지되는지 확인한다.
