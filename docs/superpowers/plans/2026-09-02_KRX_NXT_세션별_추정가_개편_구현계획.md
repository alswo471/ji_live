# KRX·NXT 세션별 추정가 개편 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 한국 주식 파생 추정가에 KRX·NXT 시간대별 세션을 표시하고, 파생 candle과 Bithumb KRW-USDT candle을 결합한 원화 추정 OHLC·차트·추종상품 거래량을 제공한다.

**Architecture:** 기존 공개 API 기반 ticker와 공급자별 cache 구조는 유지한다. 한국 시장 세션 판별, Hyperliquid candle adapter, 원화 candle 합성기를 각각 순수 모듈로 추가하고 `createCandleService`에서만 조합한다. 국내 실제 시세·거래량을 만들지 않으며 모든 파생 기반 값은 API metadata와 UI 문구로 명확히 구분한다.

**Tech Stack:** TypeScript 5.9, React 19, vinext/Vite 8, Vitest, Testing Library, Lightweight Charts 5, Hyperliquid Info API, Binance Futures API, Bithumb public API

**Spec:** `docs/superpowers/specs/2026-09-02_KRX_NXT_세션별_추정가_개편_설계.md`

## Global Constraints

- Toss Invest 자격증명과 개인 계좌 데이터는 공개 빌드에 다시 추가하지 않는다.
- KRX·NXT 실제 체결가·실제 거래량이라고 표시하지 않는다.
- 국내 전일 종가를 합법적으로 확보하지 못한 값은 `provider-24h` 비교 기준을 유지한다.
- 한국 주식 가격은 파생상품 가격과 Bithumb `KRW-USDT`를 결합한 참고 추정가로 표시한다.
- 휴장일을 확인할 수 없으면 정상 영업일이라고 추측하지 않는다.
- 미래 환율 candle로 과거 파생 candle을 채우지 않는다.
- 거래량은 `추종상품 거래량` 또는 `추종상품 거래대금`으로 표시한다.
- 기존 7개 차트 주기 `1m`, `15m`, `1h`, `4h`, `1d`, `1w`, `1M`을 유지한다.
- 기능 구현은 현재 `feature/market-dashboard-v1` worktree에서 수행한다.
- 각 구현 단위는 실패 테스트 작성, 최소 구현, 관련 테스트 통과 순서로 진행한다.
