# 대댓글 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 원댓글 비공개 후 답글을 유지하는 한 단계 대댓글을 기존 댓글 흐름에 연결한다.
**Architecture:** additive SQL migration과 server-only 읽기/쓰기 RPC, 기존 read/write service의 좁은 연결 변경, 부모별 페이지 처리를 가진 답글 UI로 구성한다. 구형 원격 DB에서는 기존 댓글 유지·답글 기능 미노출로 안전하게 배포 경계를 만든다.
**Tech Stack:** React 19, vinext, TypeScript, Supabase PostgreSQL, Vitest, Testing Library.
**Spec:** `docs/superpowers/specs/2026-09-09_대댓글_설계.md`

## Global Constraints

- 기존 1년 보관 및 legal hold 정책을 변경하지 않는다.
- 원문·작성자·작성자 UUID·관리 사유는 공개하지 않는다.
- 원격 DB 변경·자동 파기 활성화·push·merge는 이번 로컬 구현과 구분한다.
- DB reset이나 실제 사용자 데이터 삭제는 금지한다.
- 기존 스타일·익명 인증·Turnstile·댓글 합계 10회/600초 rate limit을 유지한다.
- 대댓글 깊이는 1, 원댓글 삭제·숨김 시 기존 공개 답글은 유지하고 새 답글 작성은 막는다.

  add column parent_comment_id uuid references public.community_comments(id) on delete set null;
create index community_comments_parent_created_idx
  on public.community_comments(parent_comment_id, created_at desc, id desc)

Preserve all existing columns/rows/grants and retention jobs. Use same migration safely in local database without reset; no remote application. If SQL requires a trigger for immutable parent relationships, ensure the FK SET NULL operation remains permitted without allowing arbitrary reparenting by service/clients.
