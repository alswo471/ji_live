# 공지·필독 선택 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 운영자만 일반·공지·필독을 선택하고 게시판 상단에 실제 저장된 종류대로 표시한다.

**Architecture:** 기존 작성·관리자 인증·서버 repository 경계를 확장한다. 생성은 종류와 글을 한 transaction에 저장하고 변경은 권한 재검증 후 처리한다. DB 정렬과 cursor가 동일한 kind/date/id 순서를 사용한다.

**Tech Stack:** React, vinext, TypeScript, Supabase/PostgreSQL, Vitest, Tailwind.

**Spec:** docs/superpowers/specs/2026-09-09_공지_필독_선택_설계.md

## Global Constraints

- 선택지 normal/notice/required = 일반/공지/필독. 운영자 배지를 대신 넣지 않는다.
- 순서 required → notice → normal; 같은 종류 createdAt desc, id desc. 날짜는 Asia/Seoul의 YYYY.MM.DD.
- 기존 `requireCommunityAdmin` 재사용. 클라이언트의 role/email을 믿지 않는다.
- 글·종류 원자적 생성, idempotency 유지. 숨김/삭제/제재/보관 정책 회귀 금지.
- additive migration, local-only DB 검증. 원격·env·키·공유 브랜치 변경 금지.
- 이번 Task 외 인기글 기준·메뉴·대댓글·이모지는 후속 작업이다.
