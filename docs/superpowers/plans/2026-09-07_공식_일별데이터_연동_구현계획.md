## Global Constraints

- 실제 체결 실시간 가격으로 표시하지 않는다. 기준일과 `일별`을 노출한다.
- 키는 서버 전용 DATA_GO_KR_SERVICE_KEY. Encoding은 한 번 디코딩 후 URLSearchParams로 인코딩한다. 비밀값·원본 인증 URL을 로그에 남기지 않는다.
- 기존 worktree 및 사용자의 미커밋 UI 변경을 보존한다.
- 프로세스 캐시는 공유 DB가 아니다. 다중 인스턴스 공개 확장은 별도 검증 대상이다.
- 공식 차트·전광판 지수 확대는 이 차수에 포함하지 않는다. 종목 공식 기록 표와 지수·ETF를 먼저 연결한다.

## Task 1: 서버 데이터 경계

Files: `lib/market/official-daily.ts`, `lib/market/official-daily-types.ts`, `app/api/market/official-daily/route.ts`, `tests/market/official-daily.test.ts`, `.env.example`.

Interface: `getOfficialDaily(kind: 'stock' | 'indices' | 'etf', symbol?: string): Promise<OfficialDaily>`; 결과는 kind, date(nullable), rows, stale. Row는 symbol, name, date, close, changeRate(nullable, 비율), open/high/low/volume(nullable).

- [ ] 먼저 키 이중 인코딩, 공급자 오류, 날짜·숫자·중복 검증, ETF 전체 페이지 성공/누락 실패 테스트를 작성하고 실패를 확인한다.
- [ ] 공식 Swagger로 확인한 path/parameter를 사용한다. `getStockPriceInfo`는 likeSrtnCd(카탈로그 국내 종목만), `getStockMarketIndex`는 idxNm별 조회, `getETFPriceInfo`는 최근 14일 전체 조회를 완료한 뒤 최신 확보일을 선정한다.
- [ ] 한 페이지 1,000건, 전체 20,000건 상한. totalCount/pageNo/numOfRows 및 중복을 검증하고 누락 시 순위를 반환하지 않는다. 주식 이력은 90일, 지수/ETF는 14일. 날짜는 한국 날짜 기준. OHLC의 0은 미제공으로 처리하며 거래량 0은 유지한다.
- [ ] 서버 캐시 1시간·동시 요청 병합·실패 cooldown 1분. 최종 기준일이 14일 넘으면 거부한다. 키 미설정과 일반 공급자 오류를 구분하고 사용자 입력은 allowlist로 제한한다.
- [ ] `pnpm test tests/market/official-daily.test.ts` 통과 및 원격 read-only 응답 확인.
