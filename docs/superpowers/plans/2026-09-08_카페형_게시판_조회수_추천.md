**Goal:** 기존 커뮤니티에 실제 조회수·추천과 별도 글쓰기 화면을 연결한다.

## Global Constraints

- 원격 DB reset·기존 데이터 삭제·비밀값 출력·worktree 제거 금지.
- 공개 flag·키·인증·기존 보관 정책을 변경하지 않는다.
- 조회는 actor/post 기준 rolling 24시간 1회. 추천은 원하는 boolean 상태로 멱등 변경, 본인 글 금지.
- rate limit: 조회 60회/60초, 추천·취소 합계 20회/60초, actor+daily HMAC 동시 제한.
- 실패 수치를 0으로 위장하지 않는다. UI는 지투라이브 테마와 카페형 정보 배치를 사용한다.
