# 차트 선행 데이터·그리기 도구 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** MA 120·180이 가능한 구간에서 초기 viewport 전체에 이어지고, 사용자가 추세선·수평선·수직선을 현재 브라우저에만 저장하며 그릴 수 있는 상세 차트를 만든다.

**Architecture:** candle API는 화면 범위와 별개로 최대 MA 기간 240개의 warm-up 데이터를 추가 조회한다. 그리기 상태는 순수 reducer와 브라우저 저장 hook으로 분리하고, Lightweight Charts 좌표 API와 SVG overlay를 연결해 기존 데이터·테마·viewport 생명주기를 유지한다.

**Tech Stack:** TypeScript 5.9, React 19, Lightweight Charts 5.2, Vitest 4, Testing Library, Tailwind CSS 4

**Spec:** `docs/superpowers/specs/2026-09-02_차트_선행데이터와_그리기_도구_설계.md`

**구현 상태 (2026-09-02):** 기술 검증용 프로토타입은 완료했으나 사용자 검토 결과 0.4.0 적용을 보류했다. 전체 실제 OHLCV가 아닌 파생 추정 이력에서 지표·추세선의 분석 의미가 왜곡될 수 있어 관련 코드와 추가 API 조회를 릴리스 전 제거했다. 이 계획은 시행착오와 재검토 조건을 설명하는 역사 문서로만 유지한다.

## Global Constraints

- 공급자가 반환하지 않은 2017년 이전 또는 상장 이전 candle을 만들지 않는다.
- warm-up 최대 기간은 사용자 지정 MA 최대값과 같은 `240`개다.
- drawing은 서버에 전송하지 않고 현재 기기의 해당 브라우저 `localStorage`에만 저장한다.
- drawing 저장 key는 `g2live:chart-drawings:v1:{symbol}:{interval}`이다.
- drawing 1차 범위는 추세선·수평선·수직선, 선택·삭제·undo·전체 지우기다.
- 새로운 차트 라이브러리나 drawing 의존성을 설치하지 않는다.
- 라이트·다크, 375px 모바일과 키보드 조작을 유지한다.
- 사용자 검토 전 commit·push·merge·release·배포를 하지 않는다.
- 기능·기획·참고자료·저작권과 재배포 검토 조건을 관련 Markdown 문서에 함께 기록한다.

```ts
const INTERVAL_SECONDS: Record<CandleInterval, number> = {
  '1m': 60,
  '15m': 15 * 60,
  '1h': 60 * 60,
  '4h': 4 * 60 * 60,
  '1d': 24 * 60 * 60,
  '1w': 7 * 24 * 60 * 60,
  '1M': 2_629_800,
}

export const MAX_INDICATOR_PERIOD = 240

export function getCandleRequestWindow(interval: CandleInterval, endTimeMs: number) {
  const intervalMs = INTERVAL_SECONDS[interval] * 1_000
  const visibleCount = Math.ceil(getCandleViewport(interval).visibleSeconds / INTERVAL_SECONDS[interval])
  const targetCount = visibleCount + MAX_INDICATOR_PERIOD
  return {
    startTimeMs: Math.max(0, endTimeMs - targetCount * intervalMs),
    endTimeMs,
    visibleCount,
    targetCount,
  }
}
```
